В [[11. Instruction Cycle]] мы собрали процессор целиком, но в конце наткнулись на дыру: шаги Fetch → Decode → Run → Write должны идти строго по очереди, а в схеме нет никакого «дирижёра», который бы это обеспечивал. Пора разобраться, что за метроном задаёт этот ритм — **тактовый генератор (Clock)** — и почему без него ничего не заработает.

## Прямоугольная волна

Clock — это устройство, генерирующее колеблющийся сигнал: значение на выходе то и дело переключается между 0 и 1. В принципе форма этого колебания может быть любой (синусоида, пила...), но нас интересует конкретно **прямоугольная волна** — она, как и вся остальная схема, принимает только два значения:

```
1 ───┐    ┌────┐    ┌────
     │    │    │    │
0    └────┘    └────┘
```

## Фронты: момент, где что-то происходит

Переход из 0 в 1 называется **rising edge** (восходящий фронт), из 1 в 0 — **falling edge** (нисходящий фронт).

Пока сигнал держит одно и то же значение — хоть 0, хоть 1 — в схеме ничего не меняется, это мёртвая зона: реагировать не на что. А вот в момент фронта происходит настоящее событие. Именно фронты и хочется научиться ловить.

## Edge Detector: как поймать переход

На первый взгляд кажется, что вот эта схема всегда выдаёт 0:

- один вход AND-вентиля — сам Clock;
- второй вход — тот же Clock, только пропущенный через **NOT**.

Раз одно из значений всегда инвертировано относительно другого, оба входа AND, казалось бы, никогда не станут единицей одновременно. Но у реальных вентилей есть **задержка распространения (propagation delay)** — доли наносекунды, которые нужны сигналу, чтобы пройти через вентиль. Именно она всё меняет:

| Момент | Clock | Выход NOT | Выход AND |
|---|---|---|---|
| сигнал стабильно 0 | 0 | 1 | 0 |
| Clock **только что** стал 1 | 1 | 1 *(NOT ещё не успел обновиться)* | **1** ← импульс |
| через пару наносекунд | 1 | 0 *(NOT обновился)* | 0 |
| Clock **только что** стал 0 | 0 | 0 *(NOT ещё не успел обновиться)* | 0 |
| через пару наносекунд | 0 | 1 *(NOT обновился)* | 0 |

В момент rising edge инвертор ещё «помнит» старое значение, и на долю мгновения оба входа AND оказываются единицами — на выходе проскакивает короткий импульс. На falling edge такого не происходит: прямой вход AND сразу падает в 0, и задержка инвертора уже ни на что не влияет.

Получилась схема, которая генерирует короткий импульс ровно в момент rising edge исходного сигнала — **rising edge detector**. (Зеркальная схема, реагирующая на falling edge, строится так же, но пока нам она не нужна.)

Этот короткий импульс — именно то, чего не хватало нашей памяти: сигнал, активный не «пока Clock держится в единице», а буквально на мгновение, ровно в момент переключения. Что это даёт для памяти — в [[14. Flip-Flop]].
