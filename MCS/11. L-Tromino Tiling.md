В [[10. Induction]] индукция доказывала формулу. Теперь применим её к задаче, где формул почти нет — только клетчатая доска и фигурки. Заодно увидим два новых момента: база не обязана быть нулём, а иногда, чтобы индукция сработала, теорему нужно **усилить**.

## Задача

**L-тромино (L-tromino)** — фигурка из трёх клеток в форме буквы L. Её можно поворачивать:

```
 ██     ██     █       █
 █       █     ██     ██
```

> **Теорема.** Для любого $n \geq 1$: если из доски $2^n \times 2^n$ вырезать **любую** одну клетку, оставшееся можно целиком замостить L-тромино (без наложений и выходов за край).

Доски бывают $2 \times 2$, $4 \times 4$, $8 \times 8$, $16 \times 16$, ... — сторона удваивается. Вырезанная клетка — где угодно: в углу, в центре, у края.

### Быстрая проверка: хотя бы по количеству клеток сходится?

Каждая фигурка занимает 3 клетки, значит, число клеток $4^n - 1$ обязано делиться на $3$:

| $n$ | доска        | клеток без одной | делится на 3? |
| --- | ------------ | ---------------- | ------------- |
| 1   | $2 \times 2$ | 3                | ✓ (1 фигурка) |
| 2   | $4 \times 4$ | 15               | ✓ (5)         |
| 3   | $8 \times 8$ | 63               | ✓ (21)        |

Сходится — и всегда будет сходиться, потому что $4^n - 1 = (4 - 1)(4^{n-1} + \dots + 4 + 1)$. Но это лишь **необходимое** условие: клеток подходящее количество, а сложатся ли они в L-ки — вопрос открытый. Нужно доказательство.

## Формулируем для индукции

Предикат:

$$P(n) ::= \text{«любую доску } 2^n \times 2^n \text{ без любой одной клетки можно замостить L-тромино»}$$

> **Thm:** $\forall n \geq 1.\; P(n)$

Обратите внимание: начинаем не с $0$, а с $1$. Принцип индукции работает с любой стартовой точки $b$: доказываем $P(b)$ и $P(n) \to P(n+1)$ для всех $n \geq b$ — получаем $P(n)$ для всех $n \geq b$. Костяшки домино можно начать ронять с любой.

## База: $n = 1$

Доска $2 \times 2$ без одной клетки — это три клетки, и они **сами** образуют L-тромино (в каком-то из четырёх поворотов, в зависимости от того, какая клетка вырезана):

```
 ┌───┬───┐
 │ X │ A │      X — вырезанная клетка
 ├───┼───┤      A — одна L-фигурка
 │ A │ A │
 └───┴───┘
```

Одна фигурка — и всё. $P(1)$ верно.

> Можно было стартовать и с $n = 0$: доска $1 \times 1$ без своей единственной клетки пуста, и она «замощена» нулём фигурок. Так и делает книга MCS. База с $n = 1$ просто нагляднее.

## Шаг индукции: главный трюк

Пусть $n \geq 1$, и предположим $P(n)$: **любая** доска $2^n \times 2^n$ без **любой** одной клетки замащивается (IH). **WTS** $P(n+1)$.

Берём доску $2^{n+1} \times 2^{n+1}$ с вырезанной клеткой $X$. Делим её пополам по обеим осям — получаем **четыре квадранта** размером $2^n \times 2^n$. Это как раз размер, про который знает IH.

Клетка $X$ лежит в одном из квадрантов. С ним всё хорошо: это доска $2^n \times 2^n$ без одной клетки, IH её замостит.

**Проблема:** остальные три квадранта — **целые**, без вырезанных клеток. IH про целые доски ничего не говорит (и не может: в целой доске $4^n$ клеток, это на 3 не делится).

**Трюк:** положим одну L-фигурку $C$ в самый центр большой доски так, чтобы она заняла по одной угловой клетке у каждого из трёх «целых» квадрантов:

```
 ┌─────────────┬─────────────┐
 │             │             │
 │      X      │             │
 │             │             │
 │             │ C           │
 ├─────────────┼─────────────┤
 │           C │ C           │
 │             │             │
 │             │             │
 └─────────────┴─────────────┘
```

Теперь у **каждого** из четырёх квадрантов ровно одна занятая клетка: у одного — $X$, у трёх других — клетка, накрытая $C$. Каждый квадрант — доска $2^n \times 2^n$ без одной клетки, и по IH каждый можно замостить. Четыре мощения плюс центральная фигурка $C$ покрывают всю большую доску без $X$. Это и есть $P(n+1)$.

По принципу индукции $P(n)$ верно для всех $n \geq 1$. ∎

### Как это выглядит на доске $4 \times 4$

Вырежем угловую клетку $X$. Центральная фигурка $C$ накрывает центральные углы трёх квадрантов, а дальше каждый квадрант $2 \times 2$ закрывается одной фигуркой — как в базе:

```
 ┌───┬───┬───┬───┐
 │ X │ A │ B │ B │
 ├───┼───┼───┼───┤
 │ A │ A │ C │ B │
 ├───┼───┼───┼───┤
 │ D │ C │ C │ E │
 ├───┼───┼───┼───┤
 │ D │ D │ E │ E │
 └───┴───┴───┴───┘
```

Пять фигурок, $5 \cdot 3 = 15$ клеток — ровно как в таблице выше. Для доски $8 \times 8$ всё то же самое, только каждый квадрант $4 \times 4$ заполняется этой же картинкой (с поворотом).

## Почему в теореме важно слово «любую»

Посмотрите ещё раз на шаг индукции. Для трёх квадрантов мы применяли IH к доске, у которой вырезана **угловая** клетка — та, что у центра. А для квадранта с $X$ — к доске, у которой вырезана клетка **где угодно**. Значит, IH обязан работать для любого положения дырки.

Представим, что теорема была сформулирована скромнее: «доску $2^n \times 2^n$ без **центральной** клетки можно замостить». Звучит как более простая задача — нужно разобраться всего с одним вариантом. Но индукция по ней **не проходит**: в шаге квадранты получают дырки в углах, а IH знает только про дырку в центре. Предположение индукции слишком слабое, чтобы им воспользоваться.

> Парадокс: **более сильное утверждение доказать проще**, потому что вместе с ним усиливается и предположение индукции — в шаге у нас больше «на руках». Этот приём называется **усилением предположения индукции (strengthening the induction hypothesis)**. Если индукция застряла — попробуйте доказывать больше, а не меньше.

Именно так задача и разбирается в книге MCS (раздел 5.1, [[mcs.pdf]]): там нужно замостить двор $2^n \times 2^n$, в центре которого стоит статуя Билла. Прямая индукция про «центр» не идёт, и доказывают более сильную теорему — про дырку в любом месте, — а случай с центром получают из неё как частный.

## Доказательство — это алгоритм

Доказательство выше не просто утверждает, что мощение **существует** — оно объясняет, **как его построить**. Перепишем шаг индукции как рекурсивную функцию:

```go
// tile замащивает доску размера 2^n × 2^n, у которой занята клетка hole.
func tile(board Board, n int, hole Cell) {
    if n == 1 { // база: оставшиеся три клетки — одна L-фигурка
        placeTromino(board.freeCells())
        return
    }
    quads := board.splitIntoQuadrants()
    // кладём фигурку в центр, накрывая углы трёх квадрантов без hole
    center := placeCenterTromino(board, hole)
    for _, q := range quads {
        if q.contains(hole) {
            tile(q, n-1, hole)
        } else {
            tile(q, n-1, center.cellIn(q))
        }
    }
}
```

Это классический **«разделяй и властвуй» (divide and conquer)**: задача размера $n+1$ сводится к четырём задачам размера $n$. Как и в [[10. Induction]], база индукции — базовый случай рекурсии, а IH — доверие к рекурсивному вызову. Доказательство по индукции, записанное аккуратно, почти всегда можно исполнить как программу.
