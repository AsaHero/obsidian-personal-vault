В конце [[32. Fibonacci Sequence]] обычная индукция упёрлась в стену: шаг для $F(k+1) = F(k) + F(k-1)$ требует знать что-то про **два** предыдущих члена, а предположение индукции даёт только один. Решение — разрешить себе опираться на все ступеньки ниже.

## Лестница, на которой держишься всеми ступеньками

В [[29. Induction]] переход на ступеньку $k + 1$ опирался только на ступеньку $k$. Но когда мы поднимаемся, все нижние ступеньки уже пройдены: $P(1), P(2), \dots, P(k)$ к этому моменту доказаны. Ничто не мешает использовать любую из них.

> **Сильная индукция (strong induction).** Чтобы доказать $P(n)$ для всех $n \geq a$:
>
> 1. **База:** доказать $P(a), P(a+1), \dots, P(b)$.
> 2. **Шаг:** для произвольного $k \geq b$ предположить $P(i)$ для **всех** $a \leq i \leq k$ и доказать $P(k+1)$.

Два отличия от обычной индукции:

| | Обычная индукция | Сильная индукция |
| --- | --- | --- |
| База | одно утверждение $P(a)$ | несколько: $P(a), \dots, P(b)$ |
| Предположение | $P(k)$ | $P(a) \land P(a+1) \land \cdots \land P(k)$ |

## Зачем несколько баз

Если шаг для $P(k+1)$ использует $P(k-1)$, то при самом маленьком $k$ этого $P(k-1)$ ещё не существует. Ступеньки, до которых шаг дотянуться не может, проверяются руками. Это та же ситуация, что в [[30. Induction with Inequalities]], где шаг работал только с $k \geq 1$ и потребовалась вторая база, и та же, что с начальными условиями в [[32. Fibonacci Sequence]]: соотношение смотрит на два шага назад, значит, нужны две базы.

## Пример Bazett

Рассмотрим [[31. Recursive Sequences|рекурсивную последовательность]]

$$a_1 = 1, \qquad a_2 = 3, \qquad a_k = a_{k-2} + 2a_{k-1}, \quad k \geq 3$$

Посчитаем: $a_3 = a_1 + 2a_2 = 1 + 2 \cdot 3 = 7$, $a_4 = 3 + 2 \cdot 7 = 17$, $a_5 = 7 + 2 \cdot 17 = 41$. Все нечётные.

> **Утверждение.** $a_k$ нечётно для всех $k \geq 1$.

Соотношение смотрит на два шага назад, поэтому баз две: $a_1$ и $a_2$, и шаг доказываем для $k \geq 2$.

**Доказательство.** База: $a_1 = 1$ и $a_2 = 3$ нечётны. Пусть $k \geq 2$ и $a_i$ нечётно для всех $1 \leq i \leq k$. Так как $k + 1 \geq 3$, по соотношению

$$a_{k+1} = a_{k-1} + 2a_k$$

Оба индекса $k - 1$ и $k$ лежат между $1$ и $k$, поэтому по предположению индукции $a_{k-1} = 2p + 1$ и $a_k = 2q + 1$ для некоторых $p, q \in \mathbb{Z}$. Тогда

$$a_{k+1} = (2p + 1) + 2(2q + 1) = 2(p + 2q + 1) + 1$$

и $p + 2q + 1 \in \mathbb{Z}$. Значит, $a_{k+1}$ нечётно. По принципу сильной индукции $a_k$ нечётно для всех $k \geq 1$. $\blacksquare$

| #   | Строка                                             | Откуда право                                             |
| --- | -------------------------------------------------- | -------------------------------------------------------- |
| 1   | $a_1 = 1$, $a_2 = 3$ нечётны                       | базы: начальные условия                                  |
| 2   | пусть $a_i$ нечётно для всех $1 \leq i \leq k$, $k \geq 2$ | сильное предположение индукции                   |
| 3   | $a_{k+1} = a_{k-1} + 2a_k$                         | соотношение; можно, так как $k + 1 \geq 3$               |
| 4   | $a_{k-1} = 2p + 1$, $a_k = 2q + 1$                 | I.H. для $i = k-1$ и $i = k$; [[17. Formal Definitions\|определение]] нечётного |
| 5   | $a_{k+1} = 2(p + 2q + 1) + 1$                      | подстановка и алгебра                                    |
| 6   | $p + 2q + 1 \in \mathbb{Z}$, значит $a_{k+1}$ нечётно | упаковали определение                                |

Середина доказательства — то же, что в [[18. Direct Proof]]: распаковать «нечётное» через свежих свидетелей $p$ и $q$, сложить, упаковать обратно. Индукция поставляет только **право** считать $a_{k-1}$ и $a_k$ нечётными.

> Если присмотреться, нечётность $a_k$ здесь вообще не нужна: $2a_k$ чётно при любом $a_k$. Всё решает $a_{k-1}$, член **через один** назад. Именно поэтому обычная индукция не справляется: её предположение говорит про $a_k$, а нужен $a_{k-1}$.

## Фибоначчи растёт не быстрее $2^n$

Теперь можно закрыть задачу из [[32. Fibonacci Sequence]]. Этого примера нет в видео.

> **Теорема.** $F(n) < 2^n$ для всех $n \geq 1$.

**Доказательство.** База: $F(1) = 1 < 2$ и $F(2) = 1 < 4$. Пусть $k \geq 2$ и $F(i) < 2^i$ для всех $1 \leq i \leq k$. Тогда

$$F(k+1) = F(k) + F(k-1) < 2^k + 2^{k-1} < 2^k + 2^k = 2^{k+1}$$

Первое неравенство — предположение индукции для $i = k$ и $i = k - 1$, второе — потому что $2^{k-1} < 2^k$. $\blacksquare$

Это цепочка неравенств из [[30. Induction with Inequalities]], только опирается она на две ступеньки сразу. Вместе с подсчётом вызовов из [[32. Fibonacci Sequence]] получаем: наивная рекурсивная `fib(n)` делает меньше $2^{n+1}$ вызовов. Оценка сверху экспоненциальная, и рост действительно экспоненциальный: число вызовов ведёт себя как $\varphi^n$. Такие оценки станут рабочим инструментом в [[Skiena]].

## Сильная индукция не сильнее обычной

Название обманчиво: сильная индукция не доказывает ничего такого, что нельзя доказать обычной. Определим

$$Q(n) = P(a) \land P(a+1) \land \cdots \land P(n)$$

Тогда сильное предположение «$P(i)$ для всех $a \leq i \leq k$» — это ровно $Q(k)$, а доказать $Q(k+1)$ — значит доказать $P(k+1)$ и добавить его к уже имеющейся [[9. Logical Statements|конъюнкции]]. Сильная индукция по $P$ — это обычная индукция по $Q$. Так что это не новый принцип, а удобная форма записи: держать в голове всю лестницу вместо одной ступеньки.

## Итог блока про индукцию

| Метод                          | База                    | Предположение                  | Когда                                           |
| ------------------------------ | ----------------------- | ------------------------------ | ----------------------------------------------- |
| обычная индукция               | $P(a)$                  | $P(k)$                         | $P(k+1)$ выражается через $P(k)$: суммы, $2^n$, $n!$ |
| индукция с несколькими базами  | $P(a), \dots, P(b)$     | $P(k)$, $k \geq b$             | шагу нужно $k$ побольше, как в $2^n > n$        |
| сильная индукция               | $P(a), \dots, P(b)$     | $P(i)$ для всех $a \leq i \leq k$ | шаг смотрит дальше чем на один назад: Фибоначчи |

Общая анатомия у всех трёх одна: **база**, **предположение**, **шаг**, в котором нужно найти предыдущие случаи внутри следующего. И у рекурсивных определений из [[31. Recursive Sequences]] та же анатомия: начальные условия и соотношение. Рекурсия строит объект снизу вверх, индукция по тем же ступенькам доказывает про него утверждения.
