В [[10. Truth Table]] у $\lnot p \lor \lnot q$ вышел столбец F, T, T, T. Построим теперь таблицу для совсем другой на вид формулы, $\lnot(p \land q)$:

| p | q | p ∧ q | ¬(p ∧ q) | ¬p ∨ ¬q |
| --- | --- | ----- | -------- | ------- |
| T | T | T | **F** | **F** |
| T | F | F | **T** | **T** |
| F | T | F | **T** | **T** |
| F | F | F | **T** | **T** |

Последние два столбца совпали во всех строках. Это не случайность.

## Определение

> Два утверждения **логически эквивалентны (logically equivalent)**, если у них одинаковые таблицы истинности. Пишут $P \equiv Q$.

Смысл в том, что такие формулы взаимозаменяемы. Можно заменить одну на другую в любом месте рассуждения, и истинность не изменится. Значит, вместо неудобной формулы всегда можно работать с удобной.

Чтобы показать, что формулы **не** эквивалентны, не нужна вся таблица, хватит одной строки с расхождением. Проверим частую ошибку, «раскрытие» отрицания на каждую букву:

| p | q | ¬(p ∧ q) | ¬p ∧ ¬q |
| --- | --- | -------- | ------- |
| T | F | **T** | **F** |

Значит, $\lnot(p \land q) \not\equiv \lnot p \land \lnot q$. Отрицание меняет знак связки, и об этом следующий раздел.

## Законы

Самые полезные эквивалентности проверены раз и навсегда и имеют имена.

| Закон                  | Формулы                                                                 |
| ---------------------- | ----------------------------------------------------------------------- |
| **De Morgan's laws**   | $\lnot(p \lor q) \equiv \lnot p \land \lnot q$ <br> $\lnot(p \land q) \equiv \lnot p \lor \lnot q$ |
| **Double negative**    | $\lnot(\lnot p) \equiv p$                                               |
| **Identity laws**      | $p \lor c \equiv p$ <br> $p \land t \equiv p$                           |
| **Universal bound laws** | $p \lor t \equiv t$ <br> $p \land c \equiv c$                         |
| **Negation laws**      | $p \lor \lnot p \equiv t$ <br> $p \land \lnot p \equiv c$               |
| **Commutative**        | $p \land q \equiv q \land p$ <br> $p \lor q \equiv q \lor p$            |
| **Associative**        | $(p \land q) \land r \equiv p \land (q \land r)$ <br> $(p \lor q) \lor r \equiv p \lor (q \lor r)$ |
| **Distributive**       | $p \land (q \lor r) \equiv (p \land q) \lor (p \land r)$ <br> $p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)$ |
| **Idempotent**         | $p \land p \equiv p$ <br> $p \lor p \equiv p$                           |
| **Absorption**         | $p \lor (p \land q) \equiv p$ <br> $p \land (p \lor q) \equiv p$        |

Запоминать их механически не нужно, большинство следует из здравого смысла:

- Identity: AND с заведомо истинным ничего не меняет, OR с заведомо ложным тоже. Это как $x \cdot 1 = x$ и $x + 0 = x$.
- Universal bound: одно $t$ решает исход OR, одно $c$ решает исход AND. Это как раз выводы из конца [[10. Truth Table]], записанные формулами.

**Де Морган** из них самый важный. Словами: отрицание заходит внутрь скобок и **меняет связку на противоположную**. «Неверно, что идёт дождь и холодно» значит «дождя нет **или** не холодно». В коде вы применяете его постоянно:

```go
// эти условия эквивалентны
if !(i >= 0 && i < n) { ... }
if i < 0 || i >= n { ... }
```

## Доказательство без таблицы

Зная законы, можно иногда обойтись без таблицы: последовательно заменять части формулы, пока она не упростится. Покажем, что $\lnot(\lnot p \land q) \land (p \lor q) \equiv p$:

| Шаг                                                        | Закон                     |
| ---------------------------------------------------------- | ------------------------- |
| $\lnot(\lnot p \land q) \land (p \lor q)$                  | исходная формула          |
| $\equiv (\lnot\lnot p \lor \lnot q) \land (p \lor q)$      | De Morgan                 |
| $\equiv (p \lor \lnot q) \land (p \lor q)$                 | Double negative           |
| $\equiv p \lor (\lnot q \land q)$                          | Distributive              |
| $\equiv p \lor c$                                          | Negation (и Commutative)  |
| $\equiv p$                                                 | Identity                  |

Таблица тут потребовала бы отдельный столбец на каждое подвыражение. Для двух переменных разница невелика, но при 10 переменных это уже 1024 строки против нескольких строк преобразований.

Формулы из $\lnot, \land, \lor$ теперь можно и вычислять, и упрощать. Но самая важная для математики связка пока не появилась. Любая теорема имеет вид «если ..., то ...»: [[12. Conditional Statements]].
