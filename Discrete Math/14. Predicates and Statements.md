[[9. Logical Statements|Утверждение]] бывает либо истинным, либо ложным. Но математика полна предложений вроде $x > 5$: они не истинны и не ложны, пока не сказано, чему равно $x$. Мы откладывали их с самого начала, а в конце [[13. Valid Arguments]] выяснили, что без них не обойтись.

## Предикат (predicate)

> **Предикат (predicate)** — это предложение с переменными, которое становится утверждением, когда вместо переменных подставляют значения из **области определения (domain)**.

Пусть $P(x)$: «$x$ — делитель 12», с областью определения $\mathbb{Z}^+$:

| Подстановка | Результат                                       |
| ----------- | ----------------------------------------------- |
| $P(6)$      | истинное утверждение                            |
| $P(5)$      | ложное утверждение                              |
| $P(\tfrac{1}{3})$ | **бессмыслица**: $\tfrac{1}{3} \notin \mathbb{Z}^+$ |

Последняя строка показывает, что область определения — обязательная часть предиката. Пока она не задана, неясно даже, какие значения вообще можно спрашивать.

## Предикат как функция

У нас уже есть подходящее понятие. Предикат — это [[8. Functions|функция]] из своей области определения в значения истинности:

$$P : D \to \{T, F\}$$

То есть у каждого допустимого входа ровно один ответ, да или нет. В коде это обычная функция, возвращающая `bool`:

```go
// P(x), domain: x >= 1
func isFactorOf12(x int) bool {
    return 12%x == 0
}
```

> ⚠️ Не путайте запись. Если $f(n) = n^2$, то $f(3)$ — это *число* 9. А $P(3)$ — это *утверждение*, истинное или ложное. Скобки одинаковые, природа разная.

## Truth set

Раз предикат отвечает «да» или «нет» каждому элементу области определения, то можно собрать всех, кто получил «да»:

> **Множество истинности (truth set)** предиката $P(x)$ — это все значения $x$ из области определения, для которых $P(x)$ истинно:
>
> $$\{\, x \in D \mid P(x) \,\}$$

Это в точности [[3. Set-Builder Notation|set-builder notation]]. Там мы говорили, что $P(x)$ — это некоторое «условие». Теперь у этого условия появилось точное название: это предикат. Для нашего примера:

$$\text{truth set} = \{1, 2, 3, 4, 6, 12\} \subseteq \mathbb{Z}^+$$

Как и положено результату фильтра, множество истинности всегда является подмножеством области определения.

## Предикат от двух переменных

Переменных может быть несколько. Тогда область определения состоит из [[5. Ordered Pairs|пар]], и картина замыкается ещё раз. Пусть $Q(x, y)$: «$x^2 + y^2 = 1$», с областью определения $\mathbb{R} \times \mathbb{R}$. Его множество истинности:

$$\{\, (x, y) \in \mathbb{R} \times \mathbb{R} \mid Q(x, y) \,\}$$

А ведь это та самая окружность $C$ из [[7. Two Sets Relations]]. Получается, отношение — это множество истинности некоторого предиката от двух переменных. То, что выглядело разными темами, оказывается одной: **предикат выбирает, множество хранит выбранное.**

Подстановка превращает предикат в утверждение, но говорит только об одном конкретном значении. А математические утверждения обычно звучат иначе: не «6 делит 12», а «**все** собаки — млекопитающие» или «**существует** простое чётное число». Это второй способ получить утверждение из предиката: [[15. Universal and Existential Quantifiers]].
