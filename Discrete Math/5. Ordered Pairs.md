Множества, которые мы разбирали до этого, принципиально не помнят порядок. Но точка на плоскости должна его помнить: «3 по горизонтали, 5 по вертикали» и «5 по горизонтали, 3 по вертикали» — разные точки. Записать точку как $\{3, 5\}$ не выйдет, ведь $\{3, 5\} = \{5, 3\}$. Вторая проблема: точка $(1, 1)$ превратилась бы в $\{1, 1\} = \{1\}$ и потеряла бы координату.

## Упорядоченная пара

> **Упорядоченная пара (ordered pair)** $(a, b)$ — два объекта, у которых зафиксировано, кто первый, а кто второй.

Всё её поведение задаётся одним правилом равенства:

$$(a, b) = (c, d) \quad\text{тогда и только тогда, когда}\quad a = c \;\text{ и }\; b = d$$

Сверяем позицию с позицией:

| Сравнение                     | Равны? | Почему                       |
| ----------------------------- | ------ | ---------------------------- |
| $(1, 2)$ и $(2, 1)$           | нет    | $1 \neq 2$ на первой позиции |
| $(3, \tfrac{9}{3})$ и $(\sqrt{9}, 3)$ | да | $3 = \sqrt{9}$ и $\tfrac{9}{3} = 3$ |
| $(1, 1)$ и $(1, 1)$           | да     | повтор законен: две позиции, одно значение |

Это ровно те два свойства, которых не было у множества:

| Свойство         | Множество $\{a, b\}$ | Пара $(a, b)$ |
| ---------------- | -------------------- | ------------- |
| порядок важен    | нет                  | **да**        |
| повторы важны    | нет                  | **да**        |
| скобки           | фигурные             | круглые       |

> ⚠️ Запись $(1, 2)$ встречается ещё и как **открытый интервал** чисел между 1 и 2. Совпадение обозначений неудачное, различают их по контексту.

## Не только пары

Позиций может быть больше: $(a, b, c)$ — тройка, а $(x_1, x_2, \dots, x_n)$ — **упорядоченный n-набор (ordered n-tuple)**. Равенство работает так же: позиция к позиции.

В коде ближайший аналог — `struct`: набор слотов фиксирован, а значения в них могут совпадать.

```go
type Pair struct {
    First  int
    Second int
}
// Pair{1, 2} != Pair{2, 1}, а Pair{1, 1} вполне законно
```

> Для любопытных: новый объект можно не вводить. Пару можно определить через множества, $(a, b) = \{\{a\}, \{a, b\}\}$, и правило равенства будет выполняться. Несимметричность появляется за счёт вложенности скобок. Так математики убеждаются, что множеств действительно хватает для всего.

Отдельная пара сама по себе мало полезна. Интереснее собрать **все** пары, которые можно составить из двух множеств: [[6. Cartesian Product]].
