В [[14. Predicates and Statements]] предикат становился утверждением, когда мы подставляли одно значение. Но часто хочется сказать что-то обо **всех** значениях сразу или о том, что подходящее значение **найдётся**. Такие фразы встречаются постоянно, и математикам надоело писать их словами, поэтому для них есть два символа.

## Квантор всеобщности

> **Universal quantifier** $\forall$ означает «для всех».

$$\forall x \in D,\; P(x)$$

Читается: «для всех $x$ из области определения $P(x)$ истинно». *«Каждая собака — млекопитающее»* разбирается так: $D$ — множество собак, $P(x)$: «$x$ — млекопитающее», а слово «каждая» даёт $\forall$.

Для истинности нужно, чтобы $P$ выполнялось **без исключений**, то есть множество истинности должно совпасть со всей областью определения. Значит, одного исключения, **контрпримера (counterexample)**, достаточно, чтобы всё утверждение стало ложным:

$$\forall x \in \mathbb{Z}^+,\; x \text{ — делитель 12}$$

Это ложно: контрпример $x = 5$.

## Квантор существования

> **Existential quantifier** $\exists$ означает «существует».

$$\exists x \in D,\; P(x)$$

Читается: «существует $x$ из области определения, такое что $P(x)$ истинно». *«Какой-то человек — самый старый в мире»*: $D$ — все люди, $P(x)$: «$x$ — самый старый», а слово «какой-то» даёт $\exists$.

Здесь нужен хотя бы **один** подходящий элемент, то есть множество истинности непусто. Тот же предикат с другим квантором даёт уже истинное утверждение:

$$\exists x \in \mathbb{Z}^+,\; x \text{ — делитель 12}$$

Подходит, например, $x = 6$.

> ⚠️ $\exists$ означает «**хотя бы один**», а не «ровно один». Подходящих значений может быть сколько угодно.

Обе идеи удобно сравнить через множество истинности:

| Утверждение            | Истинно, когда               | Как опровергнуть            |
| ---------------------- | ---------------------------- | --------------------------- |
| $\forall x \in D, P(x)$ | truth set $= D$             | один контрпример            |
| $\exists x \in D, P(x)$ | truth set $\neq \emptyset$  | проверить все $x$ в $D$     |

## Три разных объекта

Вот как разные записи соотносятся друг с другом:

| Запись                                | Что это     | Почему                          |
| ------------------------------------- | ----------- | ------------------------------- |
| $P$: «Руфус — млекопитающее»          | утверждение | всё определено                  |
| $P(x)$: «$x$ — млекопитающее»         | предикат    | зависит от $x$                  |
| $Q$: $\forall x \in D, P(x)$, «каждая собака — млекопитающее» | утверждение | квантор связал $x$ |

В третьей строке $x$ всё ещё есть, но подставлять в него больше нечего. **Навешивание квантора, как и подстановка, превращает предикат в утверждение.**

Теперь можно записать рассуждение о Руфусе, которое не поддавалось в [[13. Valid Arguments]]. Посылки: $\forall x \in D, P(x)$ и «Руфус $\in D$». Заключение: $P(\text{Руфус})$.

## Кванторы как циклы

На конечной области определения кванторы — это просто длинные связки. Если $D = \{a, b, c\}$:

$$\forall x \in D, P(x) \;\equiv\; P(a) \land P(b) \land P(c)$$

$$\exists x \in D, P(x) \;\equiv\; P(a) \lor P(b) \lor P(c)$$

А в коде это два самых обычных цикла:

```go
func forAll(d []int, p func(int) bool) bool {
    for _, x := range d {
        if !p(x) {
            return false // нашли контрпример
        }
    }
    return true
}

func exists(d []int, p func(int) bool) bool {
    for _, x := range d {
        if p(x) {
            return true // нашли подходящий элемент
        }
    }
    return false
}
```

Обратите внимание на случай пустого `d`: `forAll` вернёт `true`, а `exists` вернёт `false`. Контрпримера нет, потому что вообще никого нет. Это та же [[12. Conditional Statements|пустая истина]], только в коде.

## Прежние определения, записанные точно

Теперь у нас достаточно языка, чтобы вернуться к началу конспекта и записать прежние определения без слов.

**Подмножество.** $A \subseteq B$ из [[3. Set-Builder Notation]] означает:

$$\forall x,\; x \in A \to x \in B$$

И вот обещанное объяснение из [[4. Empty Set]]. Почему $\emptyset \subseteq A$? Подставляем: $\forall x,\; x \in \emptyset \to x \in A$. Гипотеза $x \in \emptyset$ ложна для любого $x$, поэтому импликация истинна **по пустому основанию** для любого $x$. Значит, утверждение истинно. То, что раньше выглядело как трюк со словами, теперь просто следует из таблицы истинности.

**Функция.** Условия из [[8. Functions]] принимают такой вид:

$$\forall x \in A,\; \exists y \in B,\; (x, y) \in F$$

$$\forall x \in A,\; \forall y, z \in B,\; \bigl((x, y) \in F \land (x, z) \in F\bigr) \to y = z$$

Здесь работает всё сразу: множества, пары, кванторы, связки и импликация.

> Кванторы можно ставить друг за другом, и порядок при этом важен: «для каждого $x$ найдётся свой $y$» и «найдётся один $y$ для всех $x$» — разные утверждения. Это отдельная тема плейлиста.

Мы умеем утверждать «для всех» и «существует». Но чтобы опровергать и доказывать от противного, надо уметь их отрицать: [[16. Negating Quantifiers]].
