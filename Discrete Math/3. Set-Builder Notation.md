[[2. Set-Roster Notation|Перечисление]] упёрлось в предел: числа между $-2$ и $5$ выписать невозможно. Зато про каждое конкретное число легко проверить, подходит оно или нет. Эта проверка и станет определением множества.

## Правило отбора

**Set-builder notation** берёт исходное множество $S$ и условие $P(x)$, которое каждый элемент либо выполняет, либо нет:

$$\{\, x \in S \mid P(x) \,\}$$

Читается: «множество всех $x$ из $S$, **таких что** $P(x)$». Слева от черты — откуда берём кандидатов, справа — кого оставляем. Например:

$$\{\, x \in \mathbb{R} \mid -2 < x < 5 \,\}$$

В коде это обычный фильтр, только кандидатов может быть бесконечно много:

```go
var result []int
for _, x := range s {
    if p(x) { // условие отбора
        result = append(result, x)
    }
}
```

## Одно условие, разные множества

Левая часть записи — не формальность. Возьмём одно и то же условие и поменяем только исходное множество:

| Запись                                      | Что получилось                     |
| ------------------------------------------- | ---------------------------------- |
| $\{x \in \mathbb{R} \mid -2 < x < 5\}$      | весь интервал числовой прямой, бесконечно много чисел |
| $\{x \in \mathbb{Z} \mid -2 < x < 5\}$      | $\{-1, 0, 1, 2, 3, 4\}$            |
| $\{x \in \mathbb{Z}^+ \mid -2 < x < 5\}$    | $\{1, 2, 3, 4\}$                   |

Обратите внимание на вторую и третью строки: одно и то же множество можно записать и через правило, и перечислением. Это две записи одного объекта.

## Подмножество

Фильтр только выбрасывает элементы, новых он не добавляет. Значит, всё, что прошло отбор, лежит в исходном $S$. У этого отношения есть имя:

> $A$ — **подмножество (subset)** $B$, пишут $A \subseteq B$, если **каждый** элемент $A$ является элементом $B$.

Итак, всегда $\{x \in S \mid P(x)\} \subseteq S$. Опровергнуть $A \subseteq B$ можно одним примером: достаточно найти элемент $A$, которого нет в $B$.

Теперь у нас два похожих значка, и их нельзя путать. $\in$ спрашивает «лежит ли этот объект внутри?», $\subseteq$ спрашивает «лежит ли внутри **всё содержимое** этого множества?»:

| Утверждение            | Верно? | Почему                                       |
| ---------------------- | ------ | -------------------------------------------- |
| $1 \in \{1, 2\}$       | да     | 1 — элемент                                  |
| $1 \subseteq \{1, 2\}$ | нет    | 1 — число, а не множество                    |
| $\{1\} \subseteq \{1, 2\}$ | да | единственный элемент $\{1\}$ есть в $\{1,2\}$ |
| $\{1\} \in \{1, 2\}$   | нет    | элементы здесь числа 1 и 2, множества $\{1\}$ среди них нет |
| $\{1\} \in \{\{1\}, 2\}$ | да   | здесь $\{1\}$ выписано как элемент           |

Через подмножества удобно записать и равенство: $A = B$ ровно тогда, когда одновременно $A \subseteq B$ и $B \subseteq A$. Так равенство множеств обычно и доказывают: два включения по очереди.

> Если $A \subseteq B$, но $A \neq B$, говорят о **строгом подмножестве (proper subset)**: $A \subsetneq B$.

## Что, если не подошёл никто

Условие может оказаться слишком строгим:

$$\{\, x \in \mathbb{R} \mid x^2 = -1 \,\}$$

Квадрат действительного числа не бывает отрицательным, так что фильтр не пропустит никого. Что тогда обозначает такая запись: ошибку или всё-таки множество? Разбираемся в [[4. Empty Set]].
