В [[28. Sequences]] член последовательности считался по номеру: $a_k = (-1)^k \cdot 3k$. Но в [[30. Induction with Inequalities]] нам больше пригодились формулы другого вида: $2^{k+1} = 2 \cdot 2^k$ и $(k+1)! = (k+1) \cdot k!$. Они не говорят, чему равен член, зато говорят, как получить его из **предыдущего**. Этого тоже достаточно, чтобы задать последовательность.

## Рекурсивное определение

Рекурсивное определение состоит из двух частей:

1. **Начальные условия (initial conditions):** несколько первых членов заданы явно. Например, $a_1 = 1$.
2. **Рекуррентное соотношение (recurrence relation):** каждый следующий член выражен через предыдущие. Например, $a_k = a_{k-1} + 3$ для $k > 1$.

Члены считаются по цепочке: $a_1 = 1$, $a_2 = a_1 + 3 = 4$, $a_3 = a_2 + 3 = 7$, $a_4 = 10$, … Каждый определён однозначно, и это снова функция $\mathbb{Z}^+ \to \mathbb{Z}$, только заданная иначе.

Условие $k > 1$ — не формальность. При $k = 1$ соотношение потребовало бы $a_0$, которого нет. Соотношение работает только там, где все нужные предыдущие члены уже определены, а всё, что ниже, покрывают начальные условия.

## Сдвиг индекса

Соотношение $a_k = a_{k-1} + 3$ — это утверждение про **все** $k > 1$, и буква $k$ в нём немая. Подставим вместо $k$ выражение $k - 2$:

$$a_{k-2} = a_{k-2-1} + 3, \quad k - 2 > 1 \qquad\text{то есть}\qquad a_{k-2} = a_{k-3} + 3, \quad k > 3$$

Это то же самое соотношение, просто записанное для другого номера. Чаще всего встречается сдвиг на единицу вперёд: $a_{k+1} = a_k + 3$ для $k \geq 1$. При сдвиге важно сдвигать и **условие** на $k$, иначе можно случайно потребовать несуществующий член.

## Старые знакомые в рекурсивной форме

Многое из прошлых заметок естественно записывается рекурсивно:

| Последовательность        | Начальное условие | Рекуррентное соотношение      |
| ------------------------- | ----------------- | ----------------------------- |
| $S_n = \sum_{k=1}^{n} k$  | $S_1 = 1$         | $S_n = S_{n-1} + n$           |
| $n!$                      | $0! = 1$          | $n! = n \cdot (n-1)!$         |
| $2^n$                     | $2^0 = 1$         | $2^n = 2 \cdot 2^{n-1}$       |

На Go рекурсивное определение переводится в рекурсивную функцию почти дословно:

```go
func a(k int) int {
	if k == 1 {
		return 1 // начальное условие
	}
	return a(k-1) + 3 // рекуррентное соотношение
}
```

Начальное условие — это base case. Без него функция уходит в бесконечную рекурсию, а математическое определение не определяет ни одного члена.

## От рекурсии к явной формуле

Рекурсивное определение удобно задавать, но неудобно вычислять: чтобы найти $a_{1000}$, нужно пройти все предыдущие. Хочется явную формулу. Распишем первые члены, не сворачивая сложения:

| $k$   | $a_k$                     | значение |
| ----- | ------------------------- | -------- |
| $1$   | $1$                       | $1$      |
| $2$   | $1 + 3$                   | $4$      |
| $3$   | $(1 + 3) + 3$             | $7$      |
| $4$   | $(1 + 3 + 3) + 3$         | $10$     |
| $k$   | $1 + \underbrace{3 + \cdots + 3}_{k-1}$ | ?  |

К единице прибавляется тройка столько раз, сколько было шагов, то есть $k - 1$. Догадка:

$$a_k = 1 + 3(k - 1)$$

## Как проверить догадку

Догадка по таблице — не доказательство, это мы уже знаем. Bazett проверяет её так: подставим формулу в правую часть соотношения и посмотрим, получится ли левая.

$$a_{k-1} + 3 = \bigl(1 + 3(k-2)\bigr) + 3 = 1 + 3(k - 2 + 1) = 1 + 3(k-1) \;\checkmark$$

И начальное условие: $1 + 3 \cdot 0 = 1 = a_1$. ✓

Почему этих двух проверок достаточно? Потому что это **индукция** из [[29. Induction]], только записанная коротко. Оформим полностью. Пусть $P(k)$: «$a_k = 1 + 3(k-1)$».

**Доказательство.** База: $a_1 = 1 = 1 + 3 \cdot 0$, то есть $P(1)$ верно. Пусть $k \geq 1$ и $a_k = 1 + 3(k-1)$. Тогда по соотношению

$$a_{k+1} = a_k + 3 = 1 + 3(k-1) + 3 = 1 + 3k = 1 + 3\bigl((k+1) - 1\bigr)$$

Это $P(k+1)$. По принципу индукции формула верна для всех $k \geq 1$. $\blacksquare$

| #   | Строка                                    | Откуда право                          |
| --- | ----------------------------------------- | ------------------------------------- |
| 1   | $a_1 = 1 + 3 \cdot 0$                     | база: начальное условие               |
| 2   | пусть $a_k = 1 + 3(k-1)$                  | предположение индукции                |
| 3   | $a_{k+1} = a_k + 3$                       | рекуррентное соотношение              |
| 4   | $= 1 + 3(k-1) + 3$                        | подставили I.H.                       |
| 5   | $= 1 + 3\bigl((k+1) - 1\bigr)$            | алгебра; это $P(k+1)$                 |

Здесь видно, что рекурсия и индукция — две стороны одного устройства. **Рекурсия задаёт** последовательность базой и шагом. **Индукция доказывает** про неё утверждения тоже базой и шагом, и шаг индукции почти всегда начинается с применения рекуррентного соотношения (строка 3).

## Обе проверки нужны

Формула $a_k = 3k$ тоже удовлетворяет соотношению: $3(k-1) + 3 = 3k$. Но $a_1 = 3 \neq 1$, начальное условие нарушено. Проверка соотношения — это шаг индукции, проверка начального условия — база, и, как мы видели в [[29. Induction]], одного шага мало.

## Два типовых семейства

Рассуждение выше обобщается без изменений:

| Название                   | Рекурсия                    | Явная формула             |
| -------------------------- | --------------------------- | ------------------------- |
| арифметическая прогрессия  | $a_k = a_{k-1} + d$         | $a_k = a_1 + d(k-1)$      |
| геометрическая прогрессия  | $a_k = r \cdot a_{k-1}$     | $a_k = a_1 \cdot r^{k-1}$ |

Наш пример — арифметическая прогрессия с $a_1 = 1$, $d = 3$. А $2^n$ — геометрическая с $r = 2$.

Пока каждый член зависел от **одного** предыдущего, и хватало одного начального условия. Что будет, если член зависит от двух предыдущих? Самый знаменитый пример: [[32. Fibonacci Sequence]].
