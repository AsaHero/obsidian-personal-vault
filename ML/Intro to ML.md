### What is ML ?
Machine Learning is subdomain of computer science that focuses on algorithms which computer learn from data without explicit programming.

### AI vs ML vs DS
Data science is a field that attempts to find patterns and draw insight from data (might use ML!). Understanding and interpreting data to solve problems or make decisions.

Machine Learning in other hand, uses algorithms to parse data, learn from it, and make predictions or decisions. It relies on statistical methods and model patterns in data.

AI is simulation of human intelligence to perform tasks autonomously, such as: problem-solving, communicating, learning and reasoning.

| Aspect         | DS                                | ML                            | AI                              |
| -------------- | --------------------------------- | ----------------------------- | ------------------------------- |
| **Definition** | Extracts insights from data.      | Enables machines to learn.    | Simulates human intelligence.   |
| **Scope**      | Broader, includes ML & others.    | Subset of AI.                 | Broadest concept.               |
| **Goal**       | Gain insights from data.          | Make accurate predictions.    | Create autonomous systems.      |
| **Key Tools**  | Python, R, Tableau, Spark.        | TensorFlow, PyTorch, Sklearn. | Robotics, NLP, Computer Vision. |
| **Use Cases**  | Business intelligence, analytics. | Fraud detection, forecasting. | Chatbots, robotics.             |
**Practical application of each filed:**
- A **Data Scientist** analyzes trends in customer data and builds an ML [[Model]] to predict churn.
- The **Machine Learning** system uses this [[Model]] to classify high-risk customers.
- An **AI system** integrates the model into a chatbot to proactively engage customers.
