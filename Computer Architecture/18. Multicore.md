Pipelining|Конвейер и суперскалярность]] выжимают больше работы из одного и того же потока инструкций на одном ядре — но у этого пути есть потолок: сколько ступеней ни добавляй, это всё ещё одна очередь инструкций, идущая через одну схему. Более прямолинейный путь к параллелизму — не углублять одну схему, а построить рядом ещё одну такую же.

## Многоядерный процессор

**Многоядерный процессор** — это кристалл, на котором размещено два и более независимых вычислительных ядра, где каждое ядро — это отдельная, полная копия всего, что мы собирали с [[5. ALU|5. ALU]] по [[9. CPU|9. CPU]]: свой ALU, свои регистры, свой блок управления, свой Instruction/Address Register.

```
┌───────────────────────┐
│ ┌────────┐ ┌────────┐ │
│ │  Core  │ │  Core  │ │
│ └────────┘ └────────┘ │
│ ┌────────┐ ┌────────┐ │
│ │  Core  │ │  Core  │ │
│ └────────┘ └────────┘ │
└───────────────────────┘
```

Транзисторов, которые закон Мура ([[16. Moore's Law|16. Moore's Law]]) продолжает добавлять на кристалл, с некоторого момента стало банально проще потратить не на ещё более глубокий конвейер одного ядра, а на несколько полных ядер сразу — каждое чуть медленнее, зато их несколько.

Ощущение от такой машины — будто вместо одной пары рук у процессора появилось сразу несколько, которые могут независимо друг от друга делать полезную работу в один и тот же момент времени.

> ⚠️ Многоядерность не ускоряет автоматически старый код. У каждого ядра свой собственный Address Register — оно по-прежнему идёт по своей единственной последовательности инструкций, ничего не зная о соседних ядрах. Чтобы реально получить выгоду от нескольких ядер, программу нужно осознанно разбить на независимые куски и раздать их по разным ядрам — это уже отдельная большая тема параллельного и конкурентного программирования, а не вопрос устройства самого кристалла.

Конвейер ускоряет одну инструкцию за раз, ядра — размножают целый процессор целиком. Есть и третий, менее очевидный способ ускорения: заставить одну-единственную инструкцию сразу обработать не одно число, а сразу восемь или шестнадцать. Переходим к [[19. SIMD|SIMD]].
