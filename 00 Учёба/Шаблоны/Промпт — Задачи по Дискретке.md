# Промпт — Задачи по Дискретке

> Вставлять в Claude Code из корня хранилища после того, как закрыт очередной блок конспектов в `Discrete Math/`. Перед вставкой поправить номера заметок, блоков и разделов Epp в первом абзаце.

---

Работаем в хранилище Obsidian. В `Discrete Math/` два источника: конспекты по плейлисту Dr. Trefor Bazett (заметки `1. Sets` … `27. There are Infinitely Many Primes`) и учебник `Discrete Mathematics with Applications [2020] Susanna S. Epp.pdf`. Пройдены блоки 1–3 из плана `00 Учёба/B — Ровный/Дискретка.md`: множества, отношения, функции; логика и кванторы; методы доказательств. По таблице «Блок → Epp» в этом плане им соответствуют разделы Epp 1.1–1.3, 2.1–2.3, 3.1–3.4, 4.1–4.8. Нужно составить набор задач для закрепления этих тем и отметить прогресс.

**Шаг 1. Собери карту тем.** Пробеги конспекты 1–27 и прочитай в Epp указанные разделы через Read с параметром pages (книга большая, 10–20 страниц за раз). Цель не повторить конспекты, а покрыть темы: если в Epp есть важное, чего в конспектах не было (например, метод элемента для множеств, предикаты с несколькими кванторами, 4.6 про иррациональность $\sqrt{2}$, 4.7–4.8 про НОД и алгоритм Евклида), это тоже идёт в набор. Пропущенные в плане разделы 2.4–2.5 не трогай.

**Шаг 2. Составь набор.** Создай `Discrete Math/Практика/Набор 1 — Блоки 1–3.md`. Задачи бери двумя способами и помечай источник:

- **Из книги.** Выбирай из Exercise Sets и Test Yourself те упражнения, которые лучше всего проверяют тему. Переформулируй по-русски, сохрани суть, укажи ссылку вида `Epp 4.3 #12`. Предпочитай задачи, у которых есть решение в Appendix B, но не только их.
- **От себя.** Придумывай задачи в стиле книги, когда нужно связать две темы, проверить типичную ошибку из конспектов (одна буква $k$ на два свидетеля, $\tfrac{1}{2}$ как свидетель чётности, обратная импликация вместо контрапозиции) или когда книжные упражнения слишком механические. Помечай `(своя)`.

Требования к набору:

- 20–25 задач, сгруппированных по блокам, внутри блока по возрастанию сложности. Примерно треть на блоки 1–2, две трети на блок 3.
- Разнообразие типов: проверка определения на примерах, перевод между словами и кванторами, отрицание утверждений, таблицы истинности и корректность аргументов, «докажите или опровергните», доказательство заданным методом, выбор метода с обоснованием. В блоке 3 по 2–3 задачи на каждый метод и хотя бы две, где метод надо выбрать самому.
- К каждой задаче ссылки на теорию: конспект `[[…]]` и раздел Epp. Хотя бы одно из двух обязательно.
- В «докажите или опровергните» примерно треть утверждений ложные. Без ловушек в формулировках.
- 3–4 задачи помечены ★ как кандидаты в артефакт «10 доказательств» из плана.
- Решений в основном файле нет. Эталонные решения и подсказки в отдельном файле `Discrete Math/Практика/Набор 1 — Решения.md`: для книжных задач с ответом в Appendix B можно сослаться на него и дать короткое решение, для остальных полное решение в формате конспектов (текст доказательства плюс таблица «Строка | Откуда право»), для ложных утверждений контрпример.
- В шапке набора: правило «рукой на бумаге, в решения смотреть только после своей попытки» и колонка или чекбокс рядом с каждой задачей, чтобы отмечать решённые.
- Русская проза, термины на английском, математика в LaTeX, обозначения как в конспектах ($\lnot p$, $\mathbb{Z}^+$).

**Шаг 3. Отметь прогресс в `00 Учёба`.** Только перечисленное:

- `B — Ровный/Дискретка.md`: в «Понимание» отметь блоки 1–3 выполненными с припиской «конспекты 1–27, карточки — нет». В таблице «Артефакт» впиши задачи со ★ в строки 1–4 с блоком 3, чекбоксы пустые. В «Лог» строка с сегодняшней датой: «Блоки 1–3: конспекты 1–27, набор задач №1 составлен (N задач, из них M из Epp)». Часы прочерком.
- `Рельсы.md`: прогресс рельса B на «41/85 видео, конспекты 1–27», следующий шаг на «Набор задач №1 рукой, потом Bazett № 42–49, индукция».
- Больше ничего не менять.

**Шаг 4. Коммит.** Только файлы набора и два файла планировщика. `.obsidian/` и посторонние изменения не стейджить. Сообщение на русском.

В конце выведи список задач по одной строке с пометкой источника, отдельно четыре со ★.

---

**Когда задачи решены:** отметить чекбоксы в наборе, перенести готовые ★ в таблицу «Артефакт» как выполненные, добавить в «Лог» строку с часами. Это делается руками или коротким промптом «отметь в Дискретка.md, что набор 1 решён, задачи № … , потрачено … ч».

**Для следующих блоков:** поменять диапазон заметок, номера блоков, разделы Epp и имя набора (`Набор 2 — Блок 4`). Структура промпта та же.
