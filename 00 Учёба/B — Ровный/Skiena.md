# Skiena — The Algorithm Design Manual

**Рельс:** B — Ровный · **Начат:** 2026-10-24 · **Оценка:** ~140 ч
**Материалы:** Steven Skiena, «The Algorithm Design Manual», 3rd ed. (2020) + [algorist.com](https://www.algorist.com/) (решения упражнений, ссылки) + лекции Skiena CSE 373 (Stony Brook) — [страница курса](https://www3.cs.stonybrook.edu/~skiena/373/)
**Зачем:** практика алгоритмов: научиться решать задачи руками, а не читать доказательства. База под CMU 15-445 и собеседования. Берётся после [[Дискретка]] (Bazett).

> **Читается только Part I** (гл. 1–13). Part II — каталог задач (Hitchhiker's Guide), открывается как справочник под конкретную задачу, подряд не читается.

## Понимание

Асимптотики, рекуррентности и инварианты цикла в [[Дискретка]] (Bazett) не разбираются — они учатся здесь, по главам ниже.

- [ ] **Гл. 1 — Introduction to Algorithm Design** · корректность, контрпримеры, индукция и рекурсия, инварианты цикла
- [ ] **Гл. 2 — Algorithm Analysis** · RAM-модель, O / Ω / Θ, суммы, логарифмы
- [ ] **Гл. 3 — Data Structures** · массивы, списки, стеки, очереди, словари, деревья поиска, priority queue
- [ ] **Гл. 4 — Sorting** · heapsort, mergesort, quicksort, binary search
- [ ] **Гл. 5 — Divide and Conquer** · рекуррентности, Master Theorem
- [ ] **Гл. 6 — Hashing and Randomized Algorithms** · нужны счёт, вероятность и матожидание (Дискретка, блоки 6–7)
- [ ] **Гл. 7 — Graph Traversal** · BFS, DFS, топологическая сортировка
- [ ] **Гл. 8 — Weighted Graph Algorithms** · MST, Dijkstra, Floyd, потоки
- [ ] **Гл. 9 — Combinatorial Search** · backtracking
- [ ] **Гл. 10 — Dynamic Programming**
- [ ] **Гл. 11 — NP-Completeness**
- [ ] **Гл. 12 — Dealing with Hard Problems** · аппроксимация, эвристики
- [ ] **Гл. 13 — How to Design Algorithms** · чек-лист Skiena

## Артефакт

- [ ] **Свой пакет алгоритмов на Go с тестами** — каждая структура и алгоритм из гл. 3–10 написаны руками, без подглядывания в готовый код, `go test` зелёный
- [ ] **Задачи: минимум 5 на главу** (гл. 1–10, итого ≥ 50) — из упражнений в конце главы и LeetCode-списков, которые Skiena там же даёт
- [ ] **2 доказательства корректности своего кода** (бинарный поиск + одно на выбор) — они же последние 2 строки таблицы в [[Дискретка]]

## Критерий закрытия

- [ ] Понимание: конспекты + карточки в колоде `CS::Алгоритмы`
- [ ] Артефакт: пакет на Go готов, тесты проходят, ≥ 50 задач решено
- [ ] Критерии закрытия [[Дискретка]] выполнены (они выполняются внутри этого курса)
- [ ] Могу без подглядывания написать quicksort, heap, BFS/DFS и Dijkstra и объяснить их сложность
- [ ] Новую задачу могу разложить по чек-листу из гл. 13: какой класс задачи, какой приём
